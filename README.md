# fp

Results as literal ok-or-err data, built and composed by pure functions. It is pure types and functions, with no side effects.

## Packages

- `@ai-swfactory-oss/fp`: a `Result` is `{ ok: true, value }` or `{ ok: false, error }`, built by `ok` and `err` and composed by `map`, `flatMap`, `match` and `pipe`.
